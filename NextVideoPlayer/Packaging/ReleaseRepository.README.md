# NextVideoPlayer

Windows용 무료 동영상 플레이어입니다.

## 다운로드

이 저장소의 **Releases**에서 최신 `NextVideoPlayer-<버전>-x64.msi`를 받으세요.
미리 보기 버전에는 pre-release 표시가 있습니다.

- Windows 10 2004 이상 / Windows 11, x64
- 재생에 필요한 DLL과 폰트가 설치 파일에 포함됩니다.
- 시작 메뉴에서 실행하고 Windows 설정의 앱 목록에서 제거할 수 있습니다.
- 설정은 사용자 AppData에 저장되며 MSI 업그레이드 시 유지됩니다.

파일 무결성은 Release의 `SHA256SUMS.txt`로 확인할 수 있습니다.

## 문제 제보

Issues에 프로그램 버전, Windows 버전, 재현 순서와 오류 내용을 남겨 주세요.

현재 구현한 기능과 앞으로 추가할 API·영상 편집·이미지 편집·LLM 도구 호출은
각 릴리스 설명에서 구분해 안내합니다.
