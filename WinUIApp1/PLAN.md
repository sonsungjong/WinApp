1. WinUI3, C# .NET10 기반의 미디어 파운데이션 GPU 가속을 사용하는 영상 스트리밍/저장/재생 프로그램
2. 주요 기능
	- 전체 화면, TOPMOST
	- 설정파일 : 프로그램 시작 시 config.json 파일을 읽어와 설정값 적용
	- 네트워크 : 카메라와 TCP/IP 소켓 통신
	- 영상 스트리밍 : 카메라의 RTSP 프로토콜 영상신호를 받아 실시간 영상재생 (FHD, 30fps 이상)
	- 영상 녹화 : 실시간 영상 데이터를 H.264 포맷으로 인코딩하여 파일로 저장 (상시녹화, 10분단위 파일분할 암호화 저장)
	- 영상 재생 : 저장된 영상을 불러오기 후 재생
	- 마우스를 하단으로 가져가면 컨트롤바 표시 (스트리밍/재생 모드 변경, 재생불러오기 복호화, 재생시작, 재생일시정지, 가로스크롤 구간이동, 시간입력구간이동)
	- 스트리밍 모드에서는 모드 변경 외에는 비활성화, 영상신호 없거나 TCP연결이 안되어있으면 중앙에 영상신호가 없습니다 문구 표시
	- 재생 모드에서는 재생불러오기를 클릭하면 날짜시간 선택창이 팝업으로 나오고 불러오기 클릭하면 이전 복호화파일 모두 지우고 선택한 파일 기준으로 이전 10분, 이후 10분만큼 복호화하여 재생준비
	- 가로스크롤은 녹화당시 시각을 표시하며 마우스로 드래그해서 +-10분 구간이동 가능
	- 시간입력구간이동은 재생불러오기처럼 날짜시간 선택창이 팝업으로 나와서 이동 누르면 현재 재생파일 중지 후 선택한 시각으로 이동시켜 이전 10분, 이후 10분 파일 복호화하여 재생준비하고 상태 원복 (재생이었으면 자동재생)
	- 배속은 지원하지 않음
	- 재생 중에도 여전히 녹화는 되고 있어야함 (TCP연결이 유지되고 있으면 상시녹화)
	- 녹화 최대 용량은 config.json에 기록값으로 제한 (오래된 폴더 및 파일부터 삭제)
	- 녹화파일 경로는 config.json에 기록된 폴더로 저장
	- 카메라의 IP와 PORT는 config.json에 기록된 값으로 연결하고 연결이 끊어지면 재접속 시도 (다른 로직에 영향 주지 않음)
	- 로딩 시간이 오래 걸리지 않게 YYYY/MM/DD 폴더 구조로 녹화파일 저장
	- 재생 모드에서 스트리밍 변경 또는 재생불러오기를 하면 재생파일 종료 후 복호화 파일 삭제)
	- 프로그램 종료 시 열려있는 TCP 소켓 닫기, 재생중이면 재생파일 닫기, 녹화중이면 녹화파일 닫기
	- 상용으로 납품해도 문제없는 라이브러리만 사용, 유료 라이브러리 사용 금지
